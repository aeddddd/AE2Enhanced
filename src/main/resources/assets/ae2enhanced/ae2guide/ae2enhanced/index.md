# AE2Enhanced 指南

欢迎来到 AE2Enhanced 指南. 本模组是 **Applied Energistics 2** 的扩展, 提供三个多方块结构,
先进工具与一系列增强.

* 使用左侧边栏浏览目录.

## 章节

* [多方块结构](multiblocks.md) - 超因果装配枢纽 / 超维度仓储中枢 / 超因果计算核心
* [装配升级卡](assembly-upgrades.md) - 并行 / 速度 / 扩容 / 自动上传

## 增强 (全局生效)

以下增强直接作用于 AE2Enhanced 合成系统, 无需任何方块:

* **超大下单量**: 单次下单数量上限提升至约 `Long.MAX_VALUE`, 输入框直接输入即可.
* **创造元件显示**: 创造 ME 存储元件中每种物品显示为 `Long.MAX_VALUE`.
