# 多方块结构

本章介绍 AE2 增强提供的三个多方块结构: 它们的用途, 搭建方式与使用说明.

* [超因果装配枢纽](assembly-hub.md) - 虚拟合成 CPU: 批量执行, 超大样板库, 升级卡体系
* [超维度仓储中枢](hyperdimensional-nexus.md) - 超维度存储 (开发中)
* [超因果计算核心](computation-core.md) - 超级合成 CPU (暂时下线, 重构中)

三个结构的任意结构方块均可连接 ME 网络; 未成型时右键各自的控制器
可打开结构界面并查看结构要求.
