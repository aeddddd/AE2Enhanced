# 特殊配方合成

AE2Enhanced 为**自引用与循环类配方**提供完整的自动合成支持: 这类配方的产物同时是自身的原料,
原生 AE2 无法为它们计算合成计划(会被判定为"递归配方"而拒绝, 或逐份展开直到计算超时).

本功能在**计算层**与**执行层**对这类配方做了专门处理, 对普通合成完全无感.

## 支持范围

* **净增殖自引用**: 如 `1A → 2A`(每次净产 1 个). 典型例子: **锻造模板复制**
  (`1 模板 + 7 钻石 + 1 下界岩 → 2 模板`). 网络中需至少 1 份产物作为"种子",
  系统会闭式计算出总调用次数, 执行时种子自动爬坡 (1→2→4→...), 只交付净产出, 种子最终返还.
* **催化剂型**: 如 `1A → 1A + 1B`(A 进出等量, 净产 B). 有 1 份 A 即可连续产出 B.
* **跨样板循环链**: 如 `A→B`、`B→A`(整体净增殖), 以及多键共享样板的复合结构
  (如赛特斯石英循环: `水晶→粉`、`水晶→充能`、`粉+充能→水晶`).
  系统会自动识别循环结构, 求出每轮的精确配平与启动种子需求.

## 下单要求

* 网络中需要有足够的**启动种子**(每种循环物品通常只需每轮消耗量, 计划确认界面会列出"初始提取").
* 特殊计划会被**独占路由**到本模组的虚拟合成单元 (测试合成 CPU / 超因果计算核心) 上执行,
  普通 CPU 不会承接这类任务; 执行时按"轮次配额"自动调度, 不会死锁, 结束后 CPU 无残留.

## 计划确认界面增强

* 自增殖/循环链条目: 行内显示 **发配轮次** (如 `循环·分 8 轮`、`自增殖·1000 次`),
  鼠标悬停显示完整详情 (每轮消耗/产出、总轮次、初始提取).
* 普通处理样板条目: 行内显示 **调用次数与估算发配轮次** (如 `调用 1000 次·约 63 轮`),
  轮次随当前选中 CPU 的协处理器数量变化.

## 暂不支持的情形(保持原生行为)

* 耐久损耗型自引用 (产物 NBT 不同的工具类配方);
* 净率恰好为 1 的中性环与净消耗环;
* 同一步骤由多个不同样板产出的欠定结构;
* 循环仅出现在深层子配方的订单.

## 示例

**锻造模板复制**: 库存 1 个肋骨盔甲纹饰 + 足量钻石/下界岩, 下单 1000 个模板 →
计划显示"自增殖·1000 次", 执行后获得 1000 个模板, 最初的种子模板仍在网络中.

**赛特斯石英循环**: `水晶→粉`、`水晶→充能水晶`、`粉+充能水晶→水晶` 三个处理样板,
库存 128 水晶 + 64 充能水晶, 下单 1000 水晶 → 计划显示"循环·分 8 轮",
每轮消耗 128 水晶、产出 256 水晶, 8 轮后交付 1000 水晶.
