# 通用内存卡

<ItemLink id="universal_memory_card" /> **通用内存卡**在设备之间复制机器配置, 并为中枢 ME 接口与 ME 网络回收节点绑定远程目标.

## 操作

- **Shift + 右键**机器: 复制其配置与升级.
- **右键**机器: 粘贴已复制的配置. 升级不足会提示; 缺少的物品可自动向网络发起合成.
- **Ctrl + 右键**: 按当前选取模式选取或取消选取目标, 之后可对全部选取目标批量粘贴.
- **Alt + 右键**: 清空绑定 (中枢 ME 接口 / ME 网络回收节点).
- **右键空气**: 打开管理 GUI.

## 模式与粘贴选项

在管理 GUI (右键空气) 中切换:

- **粘贴内容模式**: 完整(配置+升级) / 仅配置 / 仅升级. 内存卡始终保存完整副本, 模式只在粘贴时过滤生效部分.
- **选取模式** (Ctrl + 右键):
  - *单选*: 每次选取一个方块.
  - *连锁*: 洪泛选取最多 64 个连通的同类方块. 已选取的方块会被跳过, 重复点击同一网络只会补充新发现的方块.
  - *区域*: 点击两个对角, 选取框内所有受支持的机器 (最多 128 个).
- **粘贴选项**: 可独立开关粘贴时是否应用升级、朝向、侧面配置与红石控制.

## 特殊目标

- 右键[中枢 ME 接口](devices/central-interface.md): 将其设为远程目标的绑定源.
- 右键[ME 网络回收节点](devices/collector-recycler.md): 把全部已选取机器批量绑定到回收节点.
- 右键[智能样板接口](devices/smart-pattern.md): 用已选取目标查询 JEI 配方并绑定.

## 支持的设备

- AE2 部件与方块设备 (恒支持).
- 条件支持: 通用机械, 末影接口 (机器与导管), 热力膨胀 (机器、发电机、装置与储物方块), 核电工艺, 科技复兴, 工业先锋, 更多实用设备 2, Quantum Things 的机器, AE2 Stuff 与 Lazy AE2 的设备, 以及 RFTools 自动合成器.
- 原版容器 (箱子、漏斗、熔炉等): 复制时记录容器内容物快照; 粘贴时从背包或绑定网络补齐缺失的物品, 已被其他物品占用的槽位保持不变. 可在配置中关闭 (`memoryCard.vanillaContainerCopy`).

## 模组说明

- **AE2 面板**: 除设置、优先级、过滤槽与升级卡外, 还支持 P2P 隧道的频率与输入/输出端 (经 P2P 缓存注册, 要求同类型隧道)、存储/转换显示器的锁定物品/流体与锁定状态、矿物词典存储总线的过滤表达式、样板终端的合成/替换模式, 以及扳手旋转的面板朝向.

- **热力膨胀**: 复制朝向、侧面配置、红石控制、插件、过滤器与安全设置; 粘贴后会重新同步客户端, 无需重开 GUI.
- **更多实用设备 2**: 支持机器、使用者、垃圾桶、谐振器与玩家箱子; 复制红石模式、升级、机器类型与过滤器.
- **Quantum Things**: 点火器的模式可被复制并在粘贴后重新触发; 过滤器 (如物品收集器) 可被复制与应用.
- **RFTools 自动合成器**: 复制全部合成配方、记忆布局、速度模式与红石模式; 缓冲区内容物与过滤模块不复制.
