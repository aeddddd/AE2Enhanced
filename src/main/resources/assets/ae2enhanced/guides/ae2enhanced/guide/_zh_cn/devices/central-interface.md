# 中枢 ME 接口

<ItemLink id="central_me_interface" /> **中枢 ME 接口**允许远程绑定多个机器, 并且发配并回收材料, 需要使用[通用内存卡](tools/memory-card.md)来绑定远程目标.

## 远程处理器

远程执行按模组分派, 仅在对应模组安装时加载:

- 植物魔法: 魔力池, 精灵门, 泰拉凝聚板, 符文祭坛.
- 血魔法: 炼金桌, 狱火锻炉, 血之祭坛.
- 巫术: 纺车, 蒸馏器, 女巫釜锅.
- 星辉魔法: 各级祭坛. 
- 实用拓展: 充能台.
- 合成拓展: 合成核心(搭配基座), 各个等级的工作台, 量子压缩机, 末影工作台.
- 无尽贪婪: 终焉工作台.
- 龙之进化: 聚合核心.
- 神秘时代: 注魔矩阵; 坩埚 (默认每次合成后清空源质).
- 末影接口, 热力膨胀, 核电工艺 无需额外配置IO方向面


## 虚拟并行卡

<ItemLink id="virtual_parallel_card" /> **虚拟并行卡** (等级 1-8, 等级存于 NBT) 插入升级槽后, 支持的远程目标切换为虚拟合成: 不搬移实际原料, 每次虚拟合成消耗能量.

- 各等级并行数: 8 / 32 / 128 / 512 / 32,768 / 2,097,152 / 134,217,728 / 不限. 多卡并存取最高等级.
- 每次虚拟合成能耗 = 实际并行数 x `virtualParallelEnergyCost` (配置, 默认 16.0 AE). 能量不足时按比例缩减并行数.
- 通过[黑洞合成](systems/black-hole.md)获取: 等级 1 需要 1024 加速卡 + 1024 容量卡 + 64 奇点; 等级 2-6 各需 16 张低一级卡片.

相关配置: 处理超时 600 tick, 虚拟冷却每目标 20 tick, 全局 20 tick.
