Files copied (verbatim, unmodified)
-----------------------------------

All files are byte-identical copies of the corresponding entries of
appliedenergistics2-19.2.17.jar (verified by checksum). They are used at their
original filenames.

  From assets/ae2/textures/guis/ (jar)  ->  assets/ae2enhanced/textures/gui/ae2modern/

    background.png        256x256  9-slice window frame (4px border, 248x248 tileable middle)
    states.png            256x256  GUI sprite sheet (16x16 icons, slot background,
                                   toolbar button background, tab backgrounds)
    crafting.png          256x256  crafting-terminal background sheet; AE2Enhanced blits only
                                   the crafting arrow region from it
    pattern_modes.png     256x256  pattern-encoding mode backgrounds (craft 0,0 / process 0,70,
                                   stonecutting 0,140 - each 124x66)
    craft_amt.png         256x256  "set amount" dialog frame
    text_field.png        128x128  text field / search box frame

  From assets/ae2/textures/gui/sprites/ (jar)  ->  assets/ae2enhanced/textures/gui/ae2modern/

    button.png            200x20  nine-slice (border 3) button face
    button_highlighted.png 200x20 nine-slice (border 3) button face, hovered/pressed
    button_disabled.png   200x20  nine-slice (border 3) button face, disabled
    small_scroller.png      7x15  scrollbar handle (small style)
    big_scroller.png       12x15  scrollbar handle (big style; used by the reclaimed terminal)
    small_scroller_disabled.png 7x15  scrollbar handle, empty list
    big_scroller_disabled.png  12x15  scrollbar handle, empty list

  Upstream nine-slice metadata (documented here because 1.12.2 cannot read
  .mcmeta; the same numbers are hard-coded in ChromeLayout/Ae2ModernArt):

    button*.png       -> { "type": "nine_slice", "width": 200, "height": 20, "border": 3 }
    (vertical_buttons_bg.png is NOT copied)
