# AE2Enhanced

本分支是AE2Enhanced-1.20.1版本. 前置为AE2, 为AE2提供了相应的扩展内容

模组反馈和交流QQ群:**1025684217**


*当前发布版本:无*
>仍在测试开发中.

## 多方块部分

- **超因果装配枢纽**
    - 为游戏后期提供的合成解决方案, 允许以最高 `Long.MAXVALUE` 的并行执行合成样板(包含切石机/锻造台配方)
    - 对绝大部分合成情况均支持, 包括类似锻造模板的复制/递归类配方
    - 允许插入样板自动上传升级来解锁自动上传的能力
- **超维度仓储中枢** —— 达到 `BigInteger` 上限的无限容量存储结构, 支持物品、流体、气体(Mekanism)与源质(Thaumcraft), 数据持久化至外部文件, 避免存档膨胀, 并且不会因为存储大量NBT造成的卡顿和溢出问题.
- **超因果计算核心** —— 超级合成 CPU, 拥有 `Long.MAX_VALUE` 合成存储容量和 16384 并行加速器槽位, 支持动态虚拟 CPU 集群池实现多订单并发.

## 额外添加的实用物品
### 个人维度
允许自行调控规则并且自定义地板样式的独立维度

## 计划添加物品/机器
### 无线发信中心&发信编码终端
发信编码终端允许创建无线发信元件,允许无线,跨纬度的绑定方块位置,根据网络条件发送红石信号,支持编码红石信号强度等级,是否为脉冲信号,信号持续时长.

无线发信中心允许载入无线发信元件进行工作
### 维度注入
单方块机器,允许执行黑洞合成配方和代理执行AE加工机器的配方(如压印器,AAE的反应仓,EAE的电路板切割机),工作时需要放入被约束的微型奇点,将会以一定的速度消耗时间

基础并行:16,速度:20ticks.

每张加速卡-4ticks.最多放入5张变为1t.

允许自由调控并行数, 每次x2. **这样会更快地消耗微型奇点的剩余存活时间**

允许通过添加被注册为`singularity_fuel`的物品来增加剩余存活时间

### 维度能源枢纽
功能: 提供极高的AE能源缓存

形状: 立方体, 中间可选填充各个等级的元件, 共9级, 每级x32

公式:$262144\times32^i$

- 支持下单超过`Int.MAX_VALUE`的物品

## 性能

### 装配枢纽
采取虚拟合成 + 真实合成的混合机制. 即使对于极大数目的下单, `mspt` 也不会受到明显影响, 对于绝大多数 AE 允许的下单均完成了适配.

### 额外合成设定: 黑洞合成

独特的合成系统, 允许玩家创建 **微型奇点** 并且将物品投入事件视界, 转化为所需材料.

**注意**: 微型奇点只会维持 `300s`, 需要右键来开启合成, **不要离它太近!!!**
